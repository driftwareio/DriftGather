# Contributing to DriftGather

Contributions to DriftGather are welcome.

If you maintain a fork or use DriftGather as part of your own project
and develop changes that could benefit the wider community, we strongly
encourage contributing those improvements upstream.

Especially welcome are:

- bug fixes
- security improvements
- performance improvements
- accessibility improvements
- new or improved provider integrations
- generally useful features
- documentation improvements
- test coverage and reliability improvements

Not every feature from a downstream fork will necessarily fit the goals
of DriftGather. Contributions are reviewed for maintainability,
security, architectural fit, and usefulness to the wider project.

Before implementing large features, opening an issue for discussion is
recommended.
